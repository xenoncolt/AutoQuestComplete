# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include account tokens, local paths, stack traces, or other private information in a report. Use this repository's private vulnerability-reporting feature if it is available. If it is not enabled, contact the repository owner through their GitHub profile and request a private reporting channel.

Reports should include a minimal reproduction, affected plugin version, impact, and any safe-to-share logs. The maintainer should acknowledge the report, confirm the impact, prepare a fix, and publish a coordinated advisory after users have had time to update.
